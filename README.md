# Sistema Ecoturístico Chocó Biogeográfico / Urabá

## Catálogo de Elementos de Configuración de Software (ECS)
**1. Programas:** 
* Código fuente Frontend (HTML/CSS/JS) para el catálogo de tours.
* Controladores API REST (Java Spring Boot) para gestión de reservas.

**2. Datos:** 
* Esquemas de base de datos PostgreSQL para transacciones.
* Almacenamiento de multimedia (imágenes del Chocó) en Supabase.

**3. Documentación:** 
* Documento de Diseño Arquitectónico y Prototipos UI (Figma).
* Manual técnico de integración con Booking y TripAdvisor.
